# Prática de React

Projeto de estudo sobre **componentes** e **props**, feito com React + Vite.

## O que foi praticado

| Etapa | Componente | Conceito |
|-------|------------|----------|
| 1 | `Titulo.jsx` | Primeiro componente |
| 2 e 3 | `Aluno.jsx` | Props de texto e reutilização |
| 4 | `Nota.jsx` | Props numéricas |
| 5 | `Produto.jsx` | Cards de produtos |
| Desafio | `Produto.jsx` | Operador ternário (`disponivel`) |

## Como rodar

```bash
npm install     # instala as dependências
npm run dev     # roda em modo desenvolvimento
npm run build   # gera a pasta dist (versão final)
```
